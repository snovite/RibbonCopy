# 🎀 RibbonCopy

**A little collection of aesthetics, coquette symbols, kaomojis and creativity.**

[RibbonCopy](https://ribboncopy.netlify.app/) is an aesthetic copy-and-paste website designed to make discovering and using decorative text, symbols and visual elements easier.

Whether you're personalising your social media profiles, decorating your notes or creating an aesthetic digital space, RibbonCopy brings together a collection of creative elements in one place.

## ✨ Features

- **Symbols & Special Characters** – Explore decorative symbols and aesthetic text elements.
- **Kaomojis** – Discover cute text-based expressions.
- **Decorative Dividers** – Copy aesthetic separators and text decorations.
- **Fancy Letters** – Find stylised lettering for creative use.
- **Colour Palettes** – Browse colour combinations and copy HEX colour codes.
- **Custom Themes** – Explore and personalise colour combinations.

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
